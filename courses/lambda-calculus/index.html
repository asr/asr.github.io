Software

  • Robert Dockins (2007). Lambda Shell, a REPL for untyped lambda calculus.

    For installing Lambda Shell with GHC 8.6.5 or 8.8.2 you can use the following instructions (if you use cabal-install ≥ 3.0.0.0 replace install with v1-install due to this issue):

             
           $ git clone https://github.com/robdockins/shellac
           $ cd shellac
           $ cabal install
           $ cd ..
           $ git clone https://github.com/asr/lambda-shell
           $ cd lambda-shell
           $ git checkout --track origin/ghc-8.8.1
           $ cabal install
